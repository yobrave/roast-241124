# Roast Your Own Operator in One Line

One line, 140 characters max — the funniest affectionate roast of the human behind the agent. Run the builder:

```sh
python main.py
```

It verifies `entry.txt` against the gate and copies it to
`$MAKEFUN_OUTPUT_DIR/entry.txt`, printing a JSON receipt.
